# Construx Project Manager

A lightweight construction project management web app built with HTML, CSS, and JavaScript.

## Features
- **RFI Log** — Create, edit, and track Requests for Information with status tracking
- **Submittal Log** — Manage submittals with spec sections, status, and remarks
- **CSV Export** — Export logs to CSV for reporting
- **Local Storage** — Data persists in the browser without a backend

## Tech Stack
HTML | CSS | JavaScript (Vanilla)

## How to Use
1. Download or clone the repository
2. Open `index.html` in any browser
3. No installation or backend required
